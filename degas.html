DEGAS: AD-likeness of nuclei by cell type

DEGAS (step 13) learns to tell AD from control patients in bulk RNA-seq of the Mount Sinai Brain Bank (MSBB; AD = Braak stage 5-6, control = Braak stage 0-2, one sample per patient), trained together with the dataset's nuclei, and then scores every nucleus from 0 (control-like) to 1 (AD-like). Overall score levels differ between cell types for reasons unrelated to AD, so compare AD with control within a cell type; only the donor-level test (adjusted p < 0.05) says whether a cell type's scores differ between AD and control donors. See methods and the data dictionary; the same values are in the interactive explorer.

All datasets use the same MSBB patients and patient folds, but each dataset's model is trained with that dataset's nuclei and genes selected partly from them, so the AUCs differ between datasets. Each held-out fold has only 18-19 patients, so fold AUCs vary widely; the pooled AUC is the steadier figure.
